## 指摘（重要度順、6件）

### 1. 【重大な不具合】年が替わる瞬間、開花中の花火が1フレームで消える（7件）。音は鳴り続ける
- **場所**: `src/draw.mjs:125` — `sky()` が `event.date.startsWith(String(year))` で、表示中の年の花火しか描いていない。
- **症状**: 寿命が 88.8 日分あるため、10〜12月の発表は年替わりで途中消去される。消える瞬間の残り輝度は GPT-5.2 が 67%、o1 が 58%、Claude Opus 4.5 が 43%、Claude 2.1 が 39%、GPT-5.1 が 29%、GPT-4 Turbo が 22%、Claude 3.5 Sonnet v2 が 9%。破裂音（1.8 s）は鳴り続けるので、画だけが先に途切れる。
- **証拠**: `claude-review-assets/frames/L-t13.85.png` → `L-t13.97.png`、`L-t25.40` → `L-t25.50`、`L-t36.90` → `L-t37.00`（同じ箇所の拡大: `crops/zoom-t13.85.png` / `zoom-t13.97.png`）
- **修正案**: 花火の描画だけ年フィルタを外し、x 座標はその発表自身の年で計算する（`calendarPosition(e.date, yearOf(e.date))`）。年末の花火は右端で燃え尽き、左端から新しい年が始まる。花火は空の出来事なので、軸がリセットされても残るほうが自然。1月1〜14日の発表は上昇中に前年表示に隠れるので、同じ修正で一緒に直る（現データには該当なし）。

### 2. 【識別】同日・近接の発表が、混色の1つの花火に潰れる
- **場所**: `src/draw.mjs:76` — 横のずれが `±21px` しかないのに、半径は 168px（縦長 190px）。高さも全件同じ。
- **症状**: 2023-03-14 は開花 0.15 秒後から 2 色が重なった塊になる（`crops/zoom-t04.85.png`）。2026-09-22・28・29 の 4 件は 0.23 秒の間に1つの塊になる（`L-t45.30`〜`L-t45.60`、`crops/zoom-t45.60.png`）。縦長の t=4.85 では、Anthropic の amber が OpenAI の mint にほぼ隠れる（`portrait/P390-t04.85.png`）。
- **修正案**（「全件同じ半径・粒子数・寿命」と日付同期は保つ）:
  1. **会社ごとに打ち上げ高度を分ける**。例: OpenAI は `riseHeight`、Anthropic は `riseHeight − 0.5R`。会社ごとに決まった高さなので、性能を表す誤解は生じない。台帳の左右と同じく、上下で会社が分かる。
  2. 同日の組だけ、横に `±0.6R` 離す（足元の印は真の日付のまま）。
  3. **色に頼らない区別**として、会社ごとに花火の形を変える。例: OpenAI は短い尾の牡丹型、Anthropic は長い尾で、0.3 秒後に小さな火花が出る菊型。mint と amber の見分けに頼らずに済む。
  4. 任意: 開花直下に会社色のモデル名を 0.9 秒だけ出す。花火から台帳へ視線をつなげる。

### 3. 【BGM】発表音が BGM に埋もれている（計測による。聴いてはいない）
- **場所**: `src/audio.mjs:46`（毎拍のキック `.15`）、`:63`（`1/sqrt(n)`）、`:73`（破裂音 `.23 * gain`）
- **計測**: 合成を「キューあり」と「キューなし」で比べ、BGM 成分を分離した（`sfx-vs-bgm.json`）。開花後 0–300 ms の SFX/BGM 比は**全帯域で中央値 −7.8 dB（最小 −12.7、最大 −5.9）**。1 kHz 以上では中央値 +4.1 dB だが、最小 −0.5 dB。曲全体では SFX が BGM より −15.1 dB。50 ms RMS 包絡の山は毎拍のキックとベースで、発表の位置には山が立たない（`audio-envelope-cues.png`）。スペクトログラムでも、低域の拍のほうが打ち上げ音より強く出ている（`audio-spectrogram.png`）。
- **影響**: 時刻は合っているが、聴く側が「発表 = 音」と結び付けにくい可能性が高い。拍と破裂音が近いと二重の打音にもなる。
- **修正案**（全体の −18 LUFS は loudnorm で維持し、バランスだけ変える）:
  1. 破裂のたびに BGM（pad・arp・bass・kick）を −4〜−6 dB 下げる。attack 約 10 ms、release 約 400 ms。
  2. 破裂から ±90 ms 以内にある拍のキックは鳴らさない。
  3. 破裂音に 2–7 kHz の小さなクリック音（シード付き、0.3–1.4 s で減衰）を足す。描画で 0.32 秒後に出る小火花（`draw.mjs:101` の `t > .32`）と合わせる。破裂の低域も 60–120 Hz で音程が下がる成分にして重さを出す。
- 控えめな全体音量（−18 LUFS）は意図どおりとして指摘していない。問題は BGM と SFX の比率。

### 4. 【主役・視線】「空が埋まる」が画で起きず、結論では花火が消える
- **場所**: `src/draw.mjs:175`（「Watch the calendar fill the sky.」）、`:88`（fade）、`:115`（年の数字 124px `#D9E3F0`）、`ending()`
- **症状**: 花火は約 1.2 秒で暗い点になり、空に何も残らない（`L-t05.90`）。空は年ごとにリセットされる。2023 年は 11.5 秒で 5 件なので空の時間が長い（`L-t12.70`）。結論の 8.4 秒（全体の 15%）には花火が一つも無い（`L-t50.00`）。画面で一番明るい大きな要素は、ほとんどの時間で年の数字になっている。
- **修正案**:
  1. **残り火の層を作る**。各花火は、開花位置に会社色の小さな星（α 0.12–0.2）を年末まで残す。過去の年は、さらに暗いゴーストとして残す。2023 の疎らな空と 2026 の密な空が、そのまま画で比べられる。
  2. 結論では、39 個の残り火を統計の背景に残す。あるいは冒頭 1.5 秒で、日付順に 39 個が瞬く短いフィナーレを入れる（鳴らすのはチャイムだけ）。
  3. 年の数字を `C.dim` 程度に落とし、花火を最も明るい要素にする。

### 5. 【不具合・縦長】「Claude」を省くと、モデル名が数字だけになる
- **場所**: `src/draw.mjs:163` — `full.replace(/^Claude /, '')`
- **症状**: 「Claude 2」が「2」、「Claude 2.1」が「2.1」になる（`portrait/P390-t12.70.png`）。「Claude 3」は「3」、「Claude 3.5 Sonnet」は「3.5 Sonnet」になる。
- **修正案**: 省くのは、続きが英字で始まるときだけにする: `full.replace(/^Claude (?=[A-Za-z])/, '')`。例えば「Claude Opus 4.6」は「Opus 4.6」になり、「Claude 2.1」はそのまま残る。長い名前は既存の `fit()` が縮めて収める。

### 6. 【縦長 390px の可読性】補助の文字が読めず、花火の舞台も狭い
- **場所**: `src/draw.mjs` の縦長のサイズ指定。月ラベル 18px、`ONE BURST…` 21px、台帳の日付 23px、`UNOBSERVED` 16px、atlas の年 17px、フッター 18px。`:219` の `riseHeight 382 / radius 190`、`:222` の atlas。
- **症状**: 390px 幅（×0.361）にすると、上の文字は 5.8–8.3px になって読めない（`contact-portrait-390.png`）。花火の舞台は縦 1920 のうち約 30% だけで、台帳と atlas が下半分を占める。
- **修正案**: 縦長では、読ませる文字を最小 30px（390px 幅で約 11px）にする。月ラベルは JAN/APR/JUL/OCT だけにする。atlas（`:222`）は下の軸と内容が重なるので外し、空いた分で舞台を広げる（`riseHeight` 約 520、`radius` 約 230）。
